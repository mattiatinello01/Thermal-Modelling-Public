\# ThermalModelling-Public



Open-source thermodynamic simulations for HVAC \& refrigeration components.



This repository collects standalone simulation projects for heat exchangers,

compressors, and complete refrigeration cycles — built as a learning and 

portfolio resource alongside my Master's thesis in Energy Engineering.



\## Projects



| # | Project | Language | Status |

|---|---------|----------|--------|

| 02 | Plate Heat Exchanger | Python | 📅 Planned |

| 03 | Shell \& Tube Heat Exchanger | C++ | 📅 Planned |

| 04 | Full Refrigeration Cycle | Python/C++ | 📅 Planned |
